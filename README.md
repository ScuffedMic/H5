# H5 - IT-opgavepakke

Dette repository indeholder scripts og dokumentation til H5.

## Opgaveoversigt

### 1. Incident: Global Catalog Domain Controller skal udskiftes

Global Catalog Domain Controller skal udskiftes, og du skal preppe en ny og sætte den op, så den er klar til at overtage rollen.

### 2. Incident: BYOD adgangfejl pga. DHCP-scope / lease

Enheder på netværket kan ikke få adgang (BYOD) fordi dit DHCP scope er for småt eller lease er for langt. Lav en løsning der sørger for flere ledige adresser og/eller en ændring af lease.

### 3. Ny Application Server med MS SQL Server Enterprise Edition

En afdeling ønsker opsætning og installation af en ny Application Server med MS SQL Server Enterprise Edition. Opsæt og konfigurer så en afdeling (OU) fra din organisation får adgang via SSMS. Services skal køre som SA.

### 4. Application Server skal sende events til overvågning

En Application Server skal konfigureres til sende events for overvågning. Vælg en server, der passer til din organisation og håndtér disse events i din sagshåndtering.

### 5. Request For Change: Sharing / mappe med begrænset adgang

En eksisterende share (mappe) skal ændres, så kun administrationen har adgang. IT afdelingen må ikke kunne tilgå indholdet af mappen. Brug en afdeling (OU) der har adgang og én, der ikke har fra din organisation så det passer til opgaven. Mappen skal sikres så der er den bedst mulige situation for at genskabe data (ved fejl og sletning af filer i dette share).
